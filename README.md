# Personal Portfolio Website — Mst. Khairun Nessa Mim

My personal portfolio website — I am a Computer Science & Engineering student at
Southeast University, Dhaka, and an aspiring web developer.

## Live site

🌐 [khairunmim-dev.github.io](https://khairunmim-dev.github.io/)

## Features

- Responsive, mobile-first design
- Dark / light mode (choice is remembered)
- Animated hero with typing effect
- Scroll animations and hover effects
- Working contact form — messages are delivered to my email
- Downloadable CV

## Built with

- HTML5
- CSS3
- JavaScript (vanilla, no frameworks)

## Project structure

```
├── index.html        ← page content
├── style.css         ← design and colours (see :root at the top)
├── script.js         ← menu, dark mode, animations, contact form
└── assets/
    ├── images/       ← profile.jpg (profile photo)
    └── cv/           ← cv.pdf (Download CV button)
```

## Run locally

Open the folder in VS Code and run `index.html` with the **Live Server**
extension — or simply double-click `index.html` to open it in a browser.

## Updating

- **Photo:** replace `assets/images/profile.jpg` (keep the same file name)
- **CV:** replace `assets/cv/cv.pdf`
- **Text:** all visible text is in `index.html` — search and edit
- **Colours:** change the variables in `:root` at the top of `style.css`
- **New project:** copy a `project-card` block in the Projects section of
  `index.html` and edit its title, description, technologies and links

## Contact form

Messages are delivered through [FormSubmit](https://formsubmit.co) (free, no
account needed). The first submission sends one activation email — click its
link once, and from then on all messages arrive directly in my inbox. If
sending ever fails, the form falls back to the visitor's email app.
